# Sands of Chaos

A 3D top-down action shooter set in a post-apocalyptic desert world. Fight through procedurally generated levels, master dynamic combat systems, and survive waves of AI-driven enemies in this strategic, high-replayability experience.
<br
## 🎮 Overview

**Sands of Chaos** is an immersive action-shooter that combines tactical combat with procedurally generated environments. Set in a hostile desert landscape after civilization's collapse, you must survive increasingly difficult encounters using weapons, strategy, and quick reflexes.

The game emphasizes:
- **Dynamic Combat**: Real-time action with varied weapons and abilities
- **Procedural Generation**: Unique level layouts on each playthrough
- **AI Enemies**: Intelligent adversaries with adaptive behavior
- **High Replayability**: Different strategies and approaches lead to varied outcomes
